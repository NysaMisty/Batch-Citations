# 1.1.1 实现与验证记录

日期：2026-11-03。复用原批量引用、Word 桥接和 Zotero 原生文献选择器，未重写引用引擎。

- 按提供的原生窗口参考直接加载 Zotero 平台样式，使用原生标签、菜单、按钮和字体设置，移除装饰面板并收紧布局。
- 外部 COM 命令统一在 Word UI 线程执行，避免重开后文档身份判断失效；事件监听随新批次重绑，结束时释放观察目标和超时状态。
- Word 完成后先释放当前操作，再异步确认并关闭对应窗口；任务显式关联窗口，过期回调和延迟确认不影响新窗口。重复点击恢复并前置已有窗口。
- 文献列表支持 CSV/TSV/旧 JSON，附格式说明和模板，保留稳定 URI、重复检查和原子导入，错误指出行号与字段。
- Ribbon 分组 Batch Citations，中文入口不变；正文 X2 使用相同基线，16px 菜单图标按原尺寸绘制，OLE 图标保持透明。

验证：Zotero 7.0.32 / 10.0.7 + 正常启动的 Word 16.0.20527；各 54 项自动检查及界面交互、15 项原有流程、44 项原生选择器及兼容导出；12 项真实 Word 安全检查和 14 项 OLE 图标检查。原模板文件、模板会话和注册已校验恢复。没有桌面鼠标点击，预览由应用内部绘制生成。
