# 1.1.13 双击选择修正与验证

## 范围

本版基于 Git `v1.1.12` 的当前源码做局部交互修正，没有整体回退。文献列表仍与引用位置保持原有独立页签；编号队列、即时映射、重复绑定确认和显式“插入并刷新”Word 写入边界均保留。

## 实现

- `addon/content/picker.js` 将 Zotero 原生文献树的鼠标提交入口改为 `dblclick`。单击只改变原生高亮，双击捕获当前文献和当前编号后进入已有的校验、重复确认和即时映射提交流程。
- 仍保留编号队列整行切换目标、清除/排序独立按钮、Enter 键确认以及异步提交的目标修订和去重保护；方向键、搜索输入和资料库刷新不会自动绑定文献。
- `tests/picker-window.test.cjs`、`tests/picker-runtime.js` 增加单击不提交、双击只提交一次、Enter 确认和导航不提交的回归场景。
- `tests/verify-delivery.py` 更新为检查本版双击行为，防止发布核验继续接受旧的单击绑定证据。

## 验证

- Node 完整回归：206 / 206 通过。
- Zotero 7.0.32 隔离宿主：105 项通过；包含单击只高亮、双击绑定一次、编号详情区域移除、引用位置页签独立、布局与滚动检查。
- Zotero 10.0.7 隔离宿主：105 项通过；覆盖同上。
- 两版宿主的 Word 联动与窗口生命周期回归均已按隔离 profile、合成资料库、测试文档和临时注册流程运行；每版 Word 联动 53 项、生命周期 63 项通过，临时注册和模板恢复记录保留在对应测试目录。
- 最终 DLL 由 `word-addin/build.ps1` 重建，版本为 `1.1.13.0`；最终发布前会再次核对 Word 回归结果的 DLL 摘要与此构建一致。

Windows 前台激活测试在后台验证模式下确认窗口可见、内部聚焦且无 API 错误；`exactDialogForeground` / `nativeActivation` 受系统前台占用影响，不作为已通过的 OS 前台证明。

## 交付边界

双击选择只更新当前编号的 Zotero 文献映射，不写入 Word 正文；文档批量写入仍必须显式点击“插入并刷新当前文档”。本版不新增自动跳号或其他界面功能，也不改变文献映射底层结构。
