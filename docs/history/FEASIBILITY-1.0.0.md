# 1.0.0 技术可行性核查

核查日期：2026-11-03。

已将 0.2.0 的离线 DOCX 转换扩展为 Windows 桌面 Word 原位工作流。COM 加载项操作 Word 原生范围；Zotero 插件管理映射并复用官方 WinWord 引擎，不通过外部程序生成 DOCX。

实际 Word 测试覆盖未保存文档批量插入、重复刷新、光标位置文献表、数据源变更、删除后重编号、上标/正文切换、保存重开和增量批次。具体版本和结果见 [测试说明](TESTING.md)。

[Word 架构说明](WORD-INTEGRATION.md)记录模块、协议、校验、撤销、内部 API 及功能区合并调研。当前没有直接扩展官方私有 ZoteroTab，采用独立标签；文献表可继续使用官方按钮。

原位工作流仅覆盖 Windows 桌面 Word。Zotero 内部接口需要按具体版本回归；WPS、Word 网页版、macOS 和 Linux 未获原位操作支持。

0.2.0 原始核查保存在 [历史说明](history/FEASIBILITY-0.2.0.md)。其中“只处理副本”的结论不再描述 1.0.0 主工作流。
