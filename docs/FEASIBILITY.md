# 原位方案可行性与支持范围

原始方案核查日期：2026-11-03。当前版本为 1.1.9；本轮修复与实际验收见 [开发与交付报告](DEVELOPMENT-1.1.9.md)。下述原位集成和平台边界继续沿用。

已将 0.2.0 的离线 DOCX 转换扩展为 Windows 桌面 Word 原位工作流。COM 加载项操作 Word 原生范围；Zotero 插件管理映射并复用官方 WinWord 引擎，不通过外部程序生成 DOCX。

实际 Word 测试覆盖未保存文档批量插入、重复刷新、光标位置文献表、数据源变更、删除后重编号、上标/正文切换、保存重开和增量批次。具体版本和结果见 [测试说明](TESTING.md)。

[Word 架构说明](WORD-INTEGRATION.md)记录模块、协议、校验、撤销、内部 API 及功能区合并调研。本版通过备份后适配原模板共享标签标识，将两个入口合并到 Zotero 标签；原按钮与宏内容保留。自动编号检查由 Word 事件、650 ms 防抖和界面订阅驱动，没有持续轮询。

1.1.3 保留原集成、引用生成、Word 主线程调度及 CSV/TSV 编解码，补充打开请求竞态恢复、文档原编号持久化、候选缓存和原生窗口定向激活；原生界面仍直接使用 Zotero 平台资源。原编号与最终 CSL 显示编号不同，旧文档恢复必须明确确认，不能可靠自动反推。

原位工作流仅覆盖 Windows 桌面 Word。Zotero 内部接口需要按具体版本回归；WPS、Word 网页版、macOS 和 Linux 未获原位操作支持。

0.2.0 原始核查保存在 [历史说明](history/FEASIBILITY-0.2.0.md)。其中“只处理副本”的结论不再描述当前主工作流。
